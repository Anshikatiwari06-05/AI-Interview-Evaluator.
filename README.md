# AI Interview Evaluator

## 📌 Project Overview

AI Interview Evaluator is a web-based application designed to help students and job seekers practice technical interviews. It uses Artificial Intelligence to generate interview questions and evaluate users' answers, helping them improve their technical knowledge and interview skills.

## 🎯 Objectives

- Provide an environment for technical interview practice.
- Generate role-based interview questions using AI.
- Evaluate answers and provide feedback.
- Help users identify areas for improvement.
- Improve interview confidence and preparation.

## ✨ Features

- User registration and login.
- Role-based interview practice.
- AI-generated interview questions.
- Answer evaluation and scoring.
- Interview history.
- Dashboard to view interview performance.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Database Connectivity:** PyMySQL
- **AI Integration:** Google Gemini API

## 👨‍💻 Available Interview Roles

- Software Developer
- Java Developer
- Python Developer

## ⚙️ Project Workflow

1. User registers or logs into the application.
2. User selects an interview role.
3. The application generates technical interview questions using AI.
4. User submits answers.
5. AI evaluates the submitted answers.
6. The application displays scores and feedback.
7. Interview results are stored for future reference.

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Navigate to the Project Folder

```bash
cd AI-Interview-Evaluator
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file and add your required configuration, including your Gemini API key and database credentials.

**Important:** Never upload your `.env` file or expose API keys and passwords on GitHub.

### 7. Run the Application

```bash
python app.py
```

Open the local URL displayed in the terminal in your browser.
